# Task Management System

## Description
A simple Python to-do list program that displays four tasks. Each task has a title, a priority (`High`, `Medium`, or `Low`), and a completion status (`Completed` or `Pending`).

## How to Run
1. Make sure Python 3 is installed.
2. Open a terminal in the `task-management-system` folder.
3. Run:

   ```bash
   python main.py
   ```

   On some systems, use `python3 main.py` instead.
